  * Add the firewall of the admin <info>before</> the main firewall of <comment>config/packages/security.yaml</>:

    <fg=green>firewalls:
        austral_admin:
            pattern:        ^%austral_admin.path%
            lazy:           true
            provider:       austral_security_user
            user_checker:   austral.security.user_checker
            form_login:
                login_path:             austral_admin_security_login
                check_path:             austral_admin_security_login
                default_target_path:    austral_admin_index
                enable_csrf:            true
            logout:
                path:                   austral_admin_security_logout
                target:                 austral_admin_security_login</>

  * And the access rules, <info>before</> the other rules:

    <fg=green>access_control:
        - { path: '^%austral_admin.path%/(login|logout|password)', roles: PUBLIC_ACCESS }
        - { path: '^%austral_admin.path%', roles: ROLE_ADMIN_ACCESS }</>

  * Optional, in the same firewall: <comment>login_link</>, <comment>login_throttling</> (symfony/rate-limiter)
    and <comment>remember_me</>; the mails need symfony/mailer and <comment>austral_admin.mail.from</>.

  * Build the styles and the scripts of the admin (Node.js 22.18 or 24.11 and higher):

    <comment>npm install</>
    <comment>npm run build</>                    (<comment>npm run watch</> while developing)

    The recipe does not replace a <comment>package.json</> or a <comment>webpack.config.mjs</> that already exist: add
    <comment>"@austral/admin": "file:vendor/austral/admin-bundle"</> and the build tools of the recipe to the
    <comment>devDependencies</>, and call <comment>configureAustralAdmin(Encore)</> in the Webpack configuration
    (<comment>vendor/austral/admin-bundle/encore.mjs</>). A <comment>webpack.config.js</> is read before
    <comment>webpack.config.mjs</>: keep only one of them.

  * Open <comment>/austral-admin</> and log in with a root user
    (<comment>php bin/console austral:security:user --email=you@example.com --root --create</>).

  * Read the documentation at <comment>https://github.com/austral-project/admin-bundle</>
